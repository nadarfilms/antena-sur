# AntenaSur Glossary

Every term used in the interface has exactly one name.

| Term | Means | Not |
| --- | --- | --- |
| Canal | One broadcast stream in live television | Emisora, estación, stream |
| Película | A feature-length on-demand film | Film, cinta, video |
| Serie | A television show with seasons and episodes | Show, programa |
| Temporada | A numbered collection of episodes in a series | Ciclo, volumen |
| Episodio | A single video installment of a series | Capítulo, parte |
| Calidad | Video stream resolution tier (4K, 1080p, 720p) | Resolución, link, fuente |
| Subtítulos | Text caption stream synchronized with dialogue | Subs, letreros |
| Pista de Audio | A discrete language sound channel | Voz, idioma, soundtrack |
| Semillas | Peers with the complete media file | Seeders, fuentes |
| Enjambre | Total swarm of connected peers | Red, grupo P2P |
| Seguir Viendo | Resume watching media from the last timestamp | Historial, recientes |
| Favorito | Pinned channel or title in the library | Marcador, guardado |
